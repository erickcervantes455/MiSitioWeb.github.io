Práctica: Propiedad Position en CSS

1. Position: Static

Es la posición por defecto. El elemento sigue el flujo normal del documento.

Static

2. Position: Relative

Se desplaza desde su posición original usando top y left sin afectar el resto de los elementos.

Relative

3. Position: Absolute

Se posiciona con respecto a su contenedor padre más cercano que tenga position: relative.

Absolute

4. Position: Sticky

Se desplaza normalmente con el scroll hasta llegar a una posición fijada (ej. top: 10px), donde se fije temporalmente.

Sticky

5. Position: Fixed

Este elemento se sale de este cuadro y se fija en la esquina inferior derecha de tu pantalla (mira la esquina abajo a la derecha de tu navegador).

(El elemento con position: fixed se despegó de esta caja y ahora flota en tu pantalla)

¡Soy Fixed!
